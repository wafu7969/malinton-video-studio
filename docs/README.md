# 资源目录

README 顶部的界面截图引用的是本目录下的 `preview.png`。

## 怎么补上

1. 启动示例：`npm run example`
2. 浏览器打开 `http://localhost:3000`
3. 截取整个界面（建议 1600×900 以上，保留左侧预览区与右侧分镜列表、字幕时间轴）
4. 存为本目录下的 `preview.png`

## 为什么不用在线图片链接

README 会被 GitHub 和 npm 两个平台渲染。任何依赖特定服务、鉴权或实时生成的图片 URL，
在别人的浏览器里都会加载失败。把图片放进仓库是唯一稳定可靠的做法。

`package.json` 的 `files` 已包含 `docs`，所以这个图片会随包一起发布，npm 页面上也能正常显示。
